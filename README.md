Welcome to my core Data Analytics repository. This portfolio brings together **21 end-to-end analytics projects** focused on solving real-world business problems through statistical modeling, exploratory data analysis (EDA), customer profiling, and performance benchmarking across Retail, E-Commerce, Entertainment, and Operational domains.

---

## 📌 Portfolio Highlights

* **Customer & Behavioral Analytics:** Advanced segmentation using **RFM** modeling, churn profile identification, and purchase frequency/basket size analysis.
* **Product & Market Intelligence:** Conversion funnel optimization, dynamic A/B test evaluation, and market share shift dynamics.
* **Operational Analytics:** End-to-end KPI frameworks for e-commerce logistics, pricing flexibility (Airbnb), and geospatial trip durations.
* **Statistical Rigor:** Outlier detection using parametric/non-parametric methods (Z-score, IQR) and multi-variable correlation deep dives.

---

## 🛠️ Technical Stack & Tools

* **Core Language:** Python
* **Data Manipulation & Analysis:** Pandas, NumPy
* **Data Visualization:** Matplotlib, Seaborn, Plotly
* **Environment & Operations:** Jupyter Notebooks, Git / Git LFS, Docker Compose
